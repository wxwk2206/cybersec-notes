## 常见扫描器总览

| 工具            | 侧重      | 开发方         | 运行方式      | 适用场景          | 个人评价  |
| ------------- | ------- | ----------- | --------- | ------------- | ----- |
| **Nessus**    | 主机侧     | Tenable（美国） | 安装包 + 客户端 | 服务器系统漏洞扫描     | ❌ 不好用 |
| **AWVS**      | 应用侧     | Acunetix    | 安装包 + 客户端 | Web 应用漏洞扫描    | ❌ 不好用 |

## 各扫描器详解

###  Nessus —— 主机侧漏洞扫描

商业化产品，Tenable 出品。核心能力是对**服务器主机**做系统级漏洞扫描：识别操作系统版本、已装软件，比对 CVE 漏洞库，输出系统补丁、弱口令、开放端口等风险。
```bash
# 典型使用流程（GUI 操作，无命令行核心功能）
# 1. 创建扫描策略 → 2. 输入目标 IP/网段 → 3. 点击扫描 → 4. 查看报告
# 免费版限制扫描 16 个 IP，商业版按资产数收费
```
> [!warning] 不推荐
> - 安装包大、部署重，还需要 License/客户端
> - 扫描速度慢，全量扫描一个网段要跑很久
> - **误报多**：默认策略报一堆「中危」，得花大量时间人工去重
> - 偏「合规报告」型工具，做渗透测试反而显得笨重

###  AWVS —— 应用侧漏洞扫描

Acunetix Web Vulnerability Scanner，老牌 Web 漏洞扫描器。能自动爬取站点、检测 SQL 注入、XSS、命令注入、文件上传等常见 Web 漏洞，也带一些弱口令检测。
```bash
# 典型使用流程（GUI 操作）
# 1. 新建 Target，填目标 URL → 2. 选择扫描 Profile → 3. 开始扫描 → 4. 看漏洞报告
```
> [!warning] 不推荐
> - 同样是**重量级商业软件**，部署和资源占用不小
> - 爬虫对现代 SPA/JS 渲染页面经常爬不全
> - 误报 + 漏报并存，很多结果要二次确认
> - 更新慢，对 0day/新框架的覆盖不如开源社区快

###  Xray —— 应用侧漏洞扫描（长亭）
长亭科技开源的单文件 Web 漏洞扫描器，**POC 引擎**为核心，社区持续提交插件。支持主动扫描（自己爬）和被动扫描（配合 Burp 走代理）。
```bash
# ⭐ 主动扫描：让 xray 自己爬站并检测
xray webscan --basic-crawler "http://example.com" --html-output result.html

# ⭐ 被动扫描：配合 Burp 把流量转发给 xray（推荐）
# 先在 Burp 里把上游代理设为 127.0.0.1:7777
xray webscan --listen 127.0.0.1:7777 --html-output proxy_result.html

# ⭐ 指定要跑的 POC 插件
xray webscan --basic-crawler "http://example.com" --plugins sqldet,xss,cmd-injection --html-output r.html
```
被动扫描的原理：浏览器/工具发的流量 → Burp → 转发给 xray 的监听端口 → xray 对每个请求做检测 → 命中 POC 就上报。**不主动发包攻击**，所以不会产生大量无效流量，对目标更友好。
> [!success] 推荐
> - **单文件、免安装**，`xray` 直接跑
> - 支持**被动扫描**：挂在代理后面，浏览流量过一遍就出结果，不打扰业务
> - 插件/检测规则更新快，社区活跃
> - 主动 + 被动双模式，适合渗透测试
###  Goby —— 资产测绘 + 漏洞扫描一体

国产新一代安全工具，把「**资产测绘**（发现主机/端口/服务/指纹）」和「漏洞检测」做成了一张图式界面。界面上能看到网络拓扑、资产关系，点一下就能对某资产跑漏洞验证。
> [!warning] 不推荐
> - 安装包大，**下载完应用本身就很重**，启动和渲染都吃资源
> - 功能全 = 学习成本高，很多功能日常用不到
> - 扫描要装依赖组件（如指纹库、漏洞库），环境要求高

###  Fscan —— 内网综合扫描（Go 单文件）
开源内网扫描工具，Go 写的**单个可执行文件**，扔到目标机器上就能跑，主打**内网渗透前奏**：一键完成主机存活探测、端口扫描、服务识别、常见漏洞 POC 和弱口令爆破。
```bash
# ⭐ 最常用：扫一个 C 段，自动探测存活主机 + 常见端口 + 服务识别 + POC
fscan -h 192.168.1.0/24

# ⭐ 只扫端口，不跑漏洞 POC（更快更安静）
fscan -h 192.168.1.0/24 -nopoc

# ⭐ 指定端口范围
fscan -h 192.168.1.1 -p 1-65535

# ⭐ 指定服务做弱口令爆破（-m 指定模块）
fscan -h 192.168.1.0/24 -m smb
fscan -h 192.168.1.0/24 -m ssh -pass admin:123456
```

> [!success] 推荐
> - 单文件免依赖，**跨平台（Windows/Linux 都行）**，内网传上去就能用
> - 一条命令出「存活主机 + 端口 + 服务 + 漏洞」全集
> - 内置常见弱口令字典（SSH/RDP/MySQL/SMB/Redis 等）和部分 POC
> - 速度快，适合大批量网段
###  dirsearch —— Web 目录扫描（Python）

开源的 Web 目录/文件爆破工具，用字典逐条请求 URL，找出站点的隐藏目录、备份文件、后台入口等。

```bash
# ⭐ 基本用法：扫一个站点，探测常见扩展名
python dirsearch.py -u http://example.com -e php,html,js

# ⭐ 指定线程数，跑得快一些（-t）
python dirsearch.py -u http://example.com -e php -t 20

# ⭐ 指定自定义字典（-w）
python dirsearch.py -u http://example.com -w /path/to/wordlist.txt

# ⭐ 加随机 UA 降低被 WAF 拦的概率
python dirsearch.py -u http://example.com -e php --random-agent
```

 - 字典质量决定结果质量：优先用 `SecLists/Discovery/Web-Content` 等大字典
 - 目录扫出来只是第一步，扫到的 `admin/`、`backup/`、`.git`、`.bak` 文件往往才是真正的突破口
 - 频率别拉太高，容易被 WAF 封 IP，加 `--random-agent` + 适当降速更稳
