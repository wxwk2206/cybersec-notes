# 9.旁站与c段
**旁站** 和 **C段** 是渗透测试中信息收集的两个重要概念，常用于  **“同服务器”或“同网段”**  的横向扩展。

---

## 一、概念定义
| 术语 | 含义 | 关系 |
| --- | --- | --- |
| **旁站** | 与目标网站在 **同一台服务器**（同一IP）上的其他网站 | 共享同一个 IP 地址 |
| **C段** | 与目标网站 **IP 地址在同一 /24 子网**（即 IP 前三位相同，如 `1.2.3.x`）的其他主机 | 共享网段，但通常不同服务器 |


举个例子：
+ 目标网站 `example.com` 解析到 IP `1.2.3.4`
+ **旁站**：同IP下 `test.com`、`admin.example.com`（配置了虚拟主机）
+ **C段**：`1.2.3.1`、`1.2.3.5`、`1.2.3.255` 等主机上运行的其他网站或服务

---

## 二、为什么要找旁站和C段？
**核心目的**：当目标本身安全加固较好，难以直接突破时，攻击其 **同一环境下的“邻居”** ，再通过横向移动或共享漏洞间接拿下目标。

### 旁站的价值
+ **共享漏洞**：同一服务器上的不同网站可能共用一个 Web 服务器、中间件、操作系统。如果旁站存在漏洞（如上传、SQL注入、提权），可能直接控制整台服务器，从而拿下目标网站。
+ **配置不当**：可能某个旁站目录权限设置不当，可写入 webshell。
+ **IP 限制绕过**：某些后台只允许特定 IP 访问，若旁站提供了代理或跳板，可能利用之。

### C段的价值
+ **内网横向**：如果目标服务器有防火墙，但同段的其他服务器可能更脆弱。攻陷同段机器后，可以内网扫描、ARP欺骗、或利用内网服务（如 Redis 未授权、SMB 漏洞）横向移动到目标。
+ **云环境特殊性**：在云服务商（如阿里云、AWS）中，同一 C 段的机器可能属于不同租户，但仍有少数情况下存在跨租户攻击的可能（如配置错误、ARP 中毒）。不过严格云环境通常隔离，C段扫描价值相对较低，但仍值得探测开放的服务。

## 三、如何查找旁站和C段？
### 1. 查找旁站
+ **在线查询**：
    - 站长工具：`http://stool.chinaz.com/same`（输入域名或IP）
    - SecurityTrails：`https://securitytrails.com/domain/example.com/history` → 同IP历史解析
    - 微步在线：`https://x.threatbook.cn/` → IP 反查域名
    - FOFA / Shodan / Hunter：搜索 `ip="1.2.3.4"`，返回该 IP 上的所有开放端口及关联域名
+ **本地工具**：
    - `nslookup`、`dig` 先获取 IP
    - 再用 `masscan` / `nmap` 对 IP 开放的所有端口进行探测，识别 HTTP 服务绑定域名（通过 `Host` 头）
    - 使用 `gobuster vhost` 模式枚举虚拟主机（需要一定字典）

### 2. 查找 C段
+ **在线查询**：
    - FOFA / Hunter / ZoomEye 搜索 `ip="1.2.3.0/24"`
    - Shodan 搜索 `net:1.2.3.0/24`
    - C 段在线工具：`http://www.webscan.cc/`（输入目标IP，展示同段存活站点）
+ **本地扫描**：
    - `nmap -sn 1.2.3.0/24` （ping 扫描检测存活主机）
    - `masscan -p80,443,8080 1.2.3.0/24 --rate=1000` （快速探测 Web 端口）
    - `goby` 或 `fscan` 全端口+服务扫描，同时识别 Web 指纹

## 四、实战注意事项
| 场景 | 建议 |
| --- | --- |
| **旁站测试** | 优先找与目标同服务器但安全较弱的站点。注意：部分虚拟主机配置有 `open_basedir` 限制，可能无法跨目录访问，但仍存在提权或共享中间件漏洞的可能。 |
| **C段测试** | 针对 C 段中开放高危服务（如 Redis 6379、MySQL 3306、SMB 445、RDP 3389）的主机进行弱口令爆破或已知漏洞利用。 |
| **法律风险** | 未经授权对旁站及 C段扫描属于违法行为。这些技术**仅限获得书面授权的渗透测试**中使用，且通常限制在 IP 段范围内。 |


---

## 五、防守角度如何应对？
+ **旁站防御**：
    - 使用独立 IP 或云厂商的独享实例，避免与不信任站点共享同一服务器。
    - 若必须共享（如虚拟主机），严格配置 `open_basedir`、PHP 禁用危险函数、使用 Docker 或 K8s 隔离。
+ **C段防御**：
    - 配置安全组/防火墙，仅允许必需的业务端口对外，关闭高危端口（如 22、3389、6379）。
    - 部署 HIDS/EDR 监控内网横向行为。
    - 定期进行 C 段资产发现，清理未知或已下线资产。

---

## 六、一句话总结
+ **旁站**：IP 相同 → 共享服务器 → 一锅端风险。
+ **C段**：IP 相邻 → 共享邻居 → 横向突破跳板。

两者都是通过“农村包围城市”策略，从薄弱环节切入，最终攻破目标。在实际授权测试中，旁站的价值通常高于 C 段，因为同服务器一旦拿下，直接获得目标权限；而 C 段可能需要二次横向移动。
