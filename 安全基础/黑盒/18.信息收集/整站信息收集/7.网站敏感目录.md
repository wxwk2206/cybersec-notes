# 7.网站敏感目录
网站敏感目录扫描，是指在渗透测试的信息收集阶段，通过自动化工具和字典来“猜”出网站中那些未被公开链接、但真实存在的目录或文件。这些被发现的内容往往是通向服务器更深处的“地图”或“钥匙”。

它们的价值在于，官方文档（如`robots.txt`）和页面源代码有时会因配置不当泄露信息。另外，可以利用工具，基于一份常见路径字典进行“爆破”，通过分析服务器的不同响应状态码（如200、403、404）来推断路径是否存在。

### 🗺️ 敏感目录与文件清单
以下是扫描时需要重点关注的目录和文件类型。

| 类别              | 具体例子与风险说明                                                                                                                                     |
| :-------------- | :-------------------------------------------------------------------------------------------------------------------------------------------- |
| ***� 管理后台**     | `/admin`， `/manage`， `/wp-admin`（WordPress登录页）。若后台地址暴露且口令脆弱，攻击者可直接获得控制权。                                                                      |
| ***� 备份/压缩包**   | `/backup/`， `/wwwroot.zip`， `database.sql`。这些文件可能包含网站源代码、数据库密码或整个数据库，是高风险目标。                                                                  |
| **⚙️**** 配置信息** | `/.env`, `/config.php`, `/.git/config`, `WEB-INF/web.xml`。暴露文件可能导致数据库密码、API密钥泄露或源码被获取。                                                        |
| ***� 元数据文件**    | `/robots.txt`, `/.DS_Store`, `/.git/HEAD`。`robots.txt`虽用于引导搜索引擎，但常“好心办坏事”地暴露禁止访问的敏感目录，变成给攻击者的指引。而`/.DS_Store`和`/.git/`则会泄露服务器的文件结构，可被用来重建目录树。 |
| ***� 调试/测试页**   | `/phpinfo.php`， `/test.php`。`phpinfo()`页面会详尽地泄露服务器、PHP版本、路径等系统配置，是信息宝藏。                                                                       |
| ***� 开放目录浏览**   | 当访问某个目录（如`/images/`）时，直接列出了所有文件列表。这通常意味着开发者忘记配置访问权限，可能导致敏感文件被直接下载。                                                                            |
| ***� 开发/版本控制**  | `/swagger-ui.html`, `/v3/api-docs`, `/actuator`。Spring Boot、Swagger等框架的默认路径若未关闭，会暴露清晰的API文档和系统监控数据，风险极高。                                      |
| ***� 上传/编辑器**   | `/upload/`， `/ueditor`。文件上传功能点常是“重灾区”，可被用来上传Webshell获取服务器权限。                                                                                  |

### 🛠️ 主流扫描工具与实战示例
选择工具时，可以参考以下核心工具的特点说明：

| 工具名称 | 特点/优势 | 运行场景 | 一句话推荐 |
| :--- | :--- | :--- | :--- |
| **dirsearch** | 基于Python，支持多线程、递归扫描，可设置延时、排除状态码 | **命令行 (Windows/Linux/macOS)** | 功能全面，配置灵活，是目前最流行的“全能型”扫描器。 |
| **Gobuster** | 基于Go语言，速度快，资源占用低 | **命令行 (内置Kali)** | 性能极佳，不仅扫目录，还能扫子域名和vhost。 |
| **御剑 (Yujian)** | 图形化界面，简单易用 | **Windows 图形界面** | 国内早期流行的图形化工具，适合初学者快速上手。 |
| **Kali 内置工具** | 包括**DIRB**和**DirBuster**等，是渗透测试发行版的一部分。 | **命令行/图形界面 (Kali)** | 无需安装，开箱即用，是Kali Linux中的经典工具。 |
| **ffuf** | 用Go写的另一款高性能工具，支持多种灵活匹配方式 | **命令行 (跨平台)** | 以速度见长，常被用作Fuzz测试，也可用于目录发现。 |
| **Feroxbuster** | 用Rust编写，默认使用Seclists字典，支持递归和模糊匹配 | **命令行 (跨平台)** | 功能现代且强大的“新秀”，默认集成优秀字典。 |
| **Burp Suite** | 集成了Intruder模块，可用于目录扫描，并提供其他丰富功能 | **图形界面 (跨平台)** | 不仅是扫描器，更是全能Web安全测试平台，功能集成度高。 |


#### 实战命令示例（dirsearch）
假设对 `https://example.com` 进行基本扫描：

```bash
# ① 最简单的用法（使用默认配置）
python3 dirsearch.py -u https://example.com
# -u 指定目标 URL

# ② 进阶用法：自定义字典、线程数，并隐藏无趣的响应
python3 dirsearch.py -u https://example.com \
  --extensions=php,asp,txt \ # 指定文件扩展名
  -t 50 \                   # 设置线程数为 50
  -x 403,404,500            # 排除这些状态码的响应
```

#### 实战命令示例（Gobuster）
使用Gobuster进行目录扫描：

```bash
# 使用 dir 模式，扫描目标 URL，指定字典文件，设置线程为 50
gobuster dir -u http://target.com -w /path/to/wordlist.txt -t 50
# 对 HTTPS 网站使用 -k 参数忽略证书错误
gobuster dir -u https://target.com -w wordlist.txt -t 50 -k
# 常见字典位置（Kali Linux）
gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt
```

### 📚 字典选择
扫描工具的有效性高度依赖字典质量。以下是一些高质量的开源字典资源：

+ **优秀通用字典：**
    - **SecLists**：覆盖面广，其中的`/Discovery/Web_Content/`目录包含大量优秀Web字典。
    - **SaiDict**：由国内安全研究者维护，内容更贴近本土环境。
+ **获取与使用：**
    - **在线资源**：可直接从上述链接（SecLists, SaiDict）的GitHub仓库下载。
    - **Kali Linux**：部分字典已内置，位于`/usr/share/wordlists/`目录下。
    - **自定义**：根据上次的经验，针对特定CMS或框架增删修改，并使用`-w`参数指定。

### ⚙️ 提高成功率的技巧
+ **优化扫描策略**：线程数（`-t`）设置为10-30；并利用`-x`参数隐藏403、404状态码，让结果更清晰。
+ **善用扩展名**：使用`--extensions php,asp,txt`等；针对多种Web语言或CMS（如WordPress的WPscan），可使用专用字典。
+ **融合技巧**：配合上次讨论的Google Hacking（`site:example.com intitle:"index of"`），可发现更多公开目录缺口。

---

### ⚠️ 法律边界与合规使用
所有扫描活动必须在获得目标系统**所有者明确的书面授权**后，且在类似CTF比赛的**允许范围内**进行。切记**滥用工具是违法行为**。

最后提醒一下，如果你想获取更具体的技术细节，可以用“**dirsearch排除状态码**”或“**Gobuster vhost模式**”这类关键词去搜索，能帮你快速找到特定问题的解决方案。
